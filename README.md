## 📁 Structură Fișiere
- `index.html` — Pagina principală (Acasă) cu procesul în 4 pași, testimoniale și FAQ.
- `concept.html` — Filozofia Desprindere vs. Deprindere.
- `programe.html` — Serviciile și programele de terapie.
- `articole.html` — Secțiunea de resurse și articole despre deprinderi de viață.
- `despre.html` — Misiunea echipei.
- `contact.html` — Formular simplu de contact confidențial.
- `css/style.css` — Stilurile CSS complete.

## 🚀 Cum îl urci pe GitHub Pages:
1. Creează un repository nou pe GitHub (ex: `desprinderi-website`).
2. Încarcă toate fișierele extrase din această arhivă.
3. Mergi la **Settings** -> **Pages** -> Selectează branch-ul `main` / `master` și folderul `/root`.
4. Salvează! Site-ul va fi live în 1-2 minute.
